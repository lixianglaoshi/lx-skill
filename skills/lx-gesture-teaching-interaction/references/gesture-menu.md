# 手势选择与实现菜单

用户选手势，Agent 负责判断它是否适合知识关系、如何稳定识别，以及给出等价替代控制。不能以“只支持张开手掌和握拳”为由忽略用户明确选择的常见手势。

## 可选连续控制

| 用户可选动作 | 直接操控的推荐表达 | 可靠实现与边界 | 必须有的替代控制 |
| --- | --- | --- | --- |
| 捏合距离 | 抓住对象后拉长/压短线圈、拉开结构、聚拢粒子 | 拇指尖—食指尖距离 ÷ 掌宽；连续平滑 | 滑块、`[`/`]` |
| 手离镜头远近 | 掌心力场推动/吸附粒子、把模型拉近/推出 | 用经校准的掌宽/世界 landmark 相对量；不能报精确厘米 | 缩放滑块、滚轮 |
| 手掌左右/上下移动 | 牵引被抓住的模型、引导波源/粒子流/时间对象 | 用手腕/掌心平滑坐标映射，并设可视范围 | 拖拽、方向键 |
| 两手距离 | 把模型拆开/组装、把粒子云拉伸/收拢 | 用两掌心距离；两手都稳定出现才启用 | 双指缩放、滑块 |
| 手掌朝向/旋转 | 改变模型或场的真实方位，例如地轴、磁场和观察面 | 以 wrist、index MCP、pinky MCP 的叉积求掌面法向；先做中性姿态校准 | 鼠标拖拽、旋转按钮 |
| 快速前推/后拉 | 向模型发出能量脉冲、推动粒子力场、进入/退出结构层 | 用平滑 z/掌宽变化率，并明确它是离散触发，避免疲劳 | 明确按钮 |

## 可选离散控制

| 用户可选动作 | 稳定识别要点 | 合适用途 |
| --- | --- | --- |
| 张开手掌 | 四指伸展、指尖间距足够 | 展开全局、暂停观察、显示结构层 |
| 握拳 | 四指收拢且指尖靠近掌心 | 收拢、冻结、复位确认 |
| 拇指向上／向下 | 其余四指收拢，拇指方向相对掌心明确 | 离散增/减、正/负方向；不是答对/答错 |
| OK | 拇指—食指形成环，其余手指状态满足阈值 | 锁定当前状态、确认选择、显示剖切 |
| V／剪刀手（用户口中的 yes） | 食指与中指伸展，其他手指收拢 | 切换两种观察层、比较两个方案 |
| 食指指向 | 仅食指明显伸展 | 指认、选中结构、读取点位 |
| 左／右／上／下挥手 | 掌心坐标在短时间窗口内速度超过阈值，方向清楚 | 翻页、切换行星/步骤/观察面 |
| 双手合拢／分开 | 两掌心距离跨越“进入/离开”滞回阈值 | 组装/拆解、相遇/远离、镜头尺度 |

## 配置和验收

1. 生成页面在首屏放一个可折叠的“手势配置”面板，列出**用户选中的全部手势**、每个手势直接操控的对象/粒子、随后出现的学科证据、当前识别状态与鼠标/键盘替代。
2. 若用户没有指定映射，先问“这个动作想直接操控哪个对象”，或提供 2—3 个与概念对应的选项让用户选；不能悄悄替换成张手/握拳。
3. 使用 `HandLandmarker` 时自行以 landmarks 计算这些手势；若用 `GestureRecognizer`，也必须保留 landmark 连续值（如捏合、掌距和掌面方向）。
4. 每种离散手势均需候选态、稳定态、冷却态和画面提示；每种连续手势需校准按钮、当前数值和归一化说明。
5. 用户选了摄像头难以稳定判定的动作时，坦白说明并提供可调阈值/替代控件；不假装准确，不静默删掉这个功能。
