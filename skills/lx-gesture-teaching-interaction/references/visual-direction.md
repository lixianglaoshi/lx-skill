# 手势教学的视觉导演卡

先让页面有一个值得录屏的视觉世界，再用学科逻辑约束它。下面的卡不是模板复制；选择最贴近知识对象的一张，并把模型、变量、手势和教学问题改成当前主题。

## 视觉最低完成度

页面必须有一个有明确构图的主模型，而不是悬在白底中央的普通球体。优先用 Three.js 程序化构建真实 3D 层次：主模型、结构/轨迹层、环境或数据层。可组合适量 bloom、体积感雾气、微粒、扫描环、拖影、景深式层次和缓慢镜头运动，但要保证中低端电脑可运行、文字可读且不诱发眩晕。

“炫酷”只能来自正在被解释的对象：磁感线、轨道、分子键、投影面、力的矢量、波的传播、数据分布。随机烟花、无意义换肤、和知识无关的计分条不能当作视觉完成度。

## 一句话知识点的默认导演方案

### 太阳系／昼夜／四季：宇宙沙盘

- **主画面**：暗黑深空、微星尘、发光太阳、带大气辉光和云层纹理的地球；轨道以细小粒子带和光轨呈现，远处保留可降级的星幕。
- **关键层次**：太阳光束、地轴倾角、昼夜分界线、地球轨道、指定日期的季节标签。只显示当前教学需要的层，避免一次塞满所有行星资料。
- **手势高潮**：一只手捏合调节观察尺度，另一只手拖动地球到轨道位置；停在夏至/冬至时，太阳光束、昼夜边界与南北半球昼长同时改变，形成“拉开宇宙沙盘”的镜头。
- **冻结提问**：保持地轴方向不变时，地球走到轨道另一侧，哪个半球太阳高度更大？为什么？

### 欧姆定律：能量实验室

- **主画面**：深色玻璃质感的悬浮电路台；铜线、透明灯泡、发光安培表和电阻线圈被置于带扫描网格的实验舱中。
- **关键层次**：沿导线行进的电子粒子、灯泡灯丝热辉光、阻碍粒子通过的电阻结构、公式和实时读数。
- **手势高潮**：拇指上推电压，电子流从稀疏缓慢变为高速能量河，灯泡由余辉到炽亮；捏合增大电阻时，电子在电阻器前拥挤、流速下降。严禁同一手势同时改多个物理变量。
- **冻结提问**：只增大电阻时，电流粒子为什么变慢？公式中的哪个量没有变？

### 磁场／电磁铁：磁力风暴

- **主画面**：悬浮线圈和金属核心置于幽暗实验空间，磁感线是受控的蓝紫色流线和微粒带，罗盘针阵列环绕。
- **关键层次**：电流箭头、磁感线密度、磁极标记、罗盘针偏转和可选的铁屑分布。
- **手势高潮**：稳定手势改变电流方向或大小，整片磁感线反转或骤然收紧，罗盘针阵列同步翻转；暂停时保留轨迹作证据。
- **冻结提问**：为什么电流反向后不是“磁场消失”，而是指针整体反向？

### 波与声音：光波剧场

- **主画面**：深色空间中由数千个发光点组成的水面/空气介质；波峰拖出彩色余辉，两波源相遇处形成清晰干涉网。
- **关键层次**：传播方向、振幅标尺、频率读数、截面图和可开关的能量密度层。
- **手势高潮**：手掌节奏或捏合幅度驱动波源，双手形成两个波源；叠加处的亮暗结点不是装饰，而是即时显示相长与相消。
- **冻结提问**：两个波峰相遇时为什么更高？波峰和波谷相遇时去哪了？

### 三视图／观察物体：无限方块空间

- **主画面**：深色无限网格上的可发光方块建筑；方块落下有轻微体积尘粒和定位光圈，三个半透明投影面如全息玻璃从空间中展开。
- **关键层次**：真实方块、正/左/俯投影面、遮挡提示、可切换的观察者位置与纸笔网格。
- **手势高潮**：双手拉开后，模型与三个投影面同时悬浮展开；旋转观察时投影即时重绘，视觉上像把立体物“压到”三张玻璃上。
- **冻结提问**：此刻从左面看，哪一列方块被前面的方块挡住？请先画再验证。

### 分子结构／化学反应：微观星云反应舱

- **主画面**：分子在深色反应舱中以发光原子、半透明电子云与键能光带存在；反应时不使用爆炸烟花，而显示原子重组、键断裂/形成和能量变化。
- **关键层次**：原子种类、键、计数守恒、温度/碰撞能量和可选反应坐标。
- **手势高潮**：捏合进入微观尺度，手掌暂停在成键瞬间；断键的能量吸收和成键的释放以有刻度的能量带呈现。
- **冻结提问**：反应前后每种原子的数量是否变了？变化的是原子还是连接方式？

### 一次函数／抛物线：数学光轨空间

- **主画面**：暗黑三维坐标空间中，函数曲线是带微粒与流光的轨迹；参数改变时，网格、截距、切线/变化率箭头和真实情境小模型一起响应。
- **关键层次**：表达式、动态坐标投影、关键点、变化率箭头和输入输出映射。
- **手势高潮**：捏合改变斜率/开口，光轨像被拉伸的能量丝实时旋转和变形；食指悬停时，一束扫描线把某个 `x` 投到曲线上与 `y` 轴。
- **冻结提问**：斜率变大后，图像在哪些方向更陡？同一个 `x` 的输出怎样变化？

## 选型边界

- 小学低年级可用更明亮的方块世界、糖果工厂或自然场景，但模型仍要有空间和操作感，不能退回卡通选择题。
- 物理、天文、化学、几何优先深色沉浸式空间；它能让光线、轨迹和半透明结构更清楚。若投影环境很亮，必须提供高对比大屏模式。
- 手势先服务最重要的一两个变量；镜头、缩放、主题或粒子密度永远是次级控制，不能抢占学习动作。
- 不复刻任何开源项目的品牌名、UI、角色或美术素材；只吸取“多层 3D 场景 + 稳定手势 + 可读 HUD + 有冲击的转场”这一通用完成度。
