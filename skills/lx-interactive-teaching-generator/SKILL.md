# 互动教学生成器

把一个教学主题直接做成学生可操作的网页作品，而不是给用户一串网址、仓库链接、CDN 清单、在线编辑器链接，或一段“请再交给别的 AI 生成”的提示词。

## 先确定该由谁完成

| 用户要的结果 | 优先 Skill |
| --- | --- |
| 直接得到一个高质感、可操作的单文件互动教学网页 | **本 Skill** |
| 需要摄像头手势直接抓、拉、推 3D 模型或粒子 | `lx-gesture-teaching-interaction` |
| 高中立体几何、圆锥曲线或化学反应题，且答案必须精确可核 | `lx-highschool-geometry-chemistry` |
| 整节课的关卡、任务、角色、段位和迁移设计 | `lx-gamified-learning-design` |
| 要围绕预测、暂停、拆解和课堂提问设计慢速 3D 教学过程 | `lx-3d-teaching-animation` |

本 Skill 的优势是“一句话主题也能直接出一个能玩、能演示、视觉完成度高的互动页”。不要为了避免与相邻 Skill 重叠而删掉真实 3D、交互控件或视觉表现。

用户明确提出摄像头、手势、MediaPipe、手掌/捏合/拇指控制等需求时，优先转用 `lx-gesture-teaching-interaction`：它要求手势直接抓、拉、推模型或扰动粒子，读数只作为结果，并保证摄像头权限、识别防抖和鼠标/键盘替代。若用户只要鼠标、触屏或按钮互动，继续由本 Skill 直接完成。

## 不可退让的交付规则

1. **最终交付必须是一个 `.html` 文件。** 有文件写入能力时，将完整网页写到用户指定位置；未指定则写到当前工作目录，命名清楚，例如 `互动-函数斜率.html`。交付时只报告这个文件路径和必要的使用说明。
2. 不得只回复网址、GitHub 地址、在线预览链接、CDN 地址、零散代码片段或让用户另找开发者。若宿主无法写文件，回复必须是从 `<!DOCTYPE html>` 到 `</html>` 的完整 HTML，且没有其他说明文字，让用户可直接保存为 `.html`。
3. 页面不能依赖本地服务器、构建命令、私有 API、账号登录或用户手工拼接多个文件。稳定 CDN 可用于增强；用户明确要离线使用时，必须不使用外链并以内联实现或可运行的简化替代。
4. 一个页面只服务一个明确的学习关系。先让学生操控、预测、观察和解释，再提供可折叠的检验；不能把题目换成几个选择按钮就称为互动教学。
5. 若主题本质是空间结构、分子、机械、天体或运动过程，必须生成**真正可旋转、缩放、拖拽的 Three.js 3D 场景**（含光照、材质、相机控制与对象关系），不能用静态截图、CSS 假 3D 或二维方块冒充。函数、统计和流程等 2D 关系则优先用真实 SVG/Canvas，避免无意义的 3D。

## 执行

完整读取并遵循 `vendor/aetherviz-master/SKILL.md`。它是本 Skill 的互动网页生成核心，规定了 Three.js、SVG、KaTeX、D3、滑块、播放/暂停、可折叠测验、响应式布局和高质感视觉的完整实现要求。

在遵循上游规则的同时，补足以下 LX 教学判断：

- 从用户已给出的年级、主题、学生困难和课堂设备出发；信息不足但不影响网页成立时自行采用合理默认值，直接开始制作，不用一长串反问拖住交付。
- 页面必须有：标题与目标、一个可操作核心模型、操作后可读的反馈、一个先预测后验证的动作，以及回到语言/公式/纸笔表达/新情境的迁移出口。
- 大屏课堂优先让教师演示—学生预测—学生解释；个人设备场景保留自主拖拽与重置。所有界面跟随用户语言，中文请求默认简体中文。
- 真正运行或检查生成页面：初始状态可读，控件确实改变模型，重置有效，公式/标签与对象同步，没有明显控制台错误。若不能实际预览，要诚实说明未预览的范围，但仍交付完整 HTML。
- 若用户明确只要“给编程 Agent 的开发提示词”，可以给提示词；否则默认直接生成 HTML 成品，而不是提示词。
