## 使用边界

1. 报道不是课程标准，也不是研究结论。
2. 报道中的成绩变化、学生个案和评价性表述，只有在用户提供原始记录并确认后，才能进入案例证据层。
3. Skill 设计时优先采用用户回忆、教案、游戏流程、学生作品、课堂录像或观察记录。
4. 对外发布时保留链接和来源，不扩大推断，不声称“游戏化必然提高成绩”。
